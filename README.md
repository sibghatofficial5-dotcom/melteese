# MELTEESE – Let the taste melt you!

Interactive online menu and ordering website for **MELTEESE®**, Cantonment Plaza, Sialkot.

## Features

- **Interactive Menu**: Deals, Beef burgers, Chicken burgers, Fries and sides, Wraps and sandwiches, Sauces and drinks.
- **Cart & Order Review**: Add/remove quantities with instant calculation in PKR (Rs).
- **Direct WhatsApp Ordering**: One-click order submission pre-formatted with line items, quantities, totals, and delivery details.
- **Responsive & Lightweight**: Single-page application built with vanilla HTML5, CSS3, and modern JavaScript (no external runtime dependencies or build steps required).

## Quick Start

Open `index.html` directly in any modern web browser or deploy to any static host (GitHub Pages, Vercel, Netlify).

### Deploy to GitHub Pages
1. Go to repository **Settings** > **Pages**.
2. Select `main` branch as the Source and `/ (root)` folder.
3. Save to publish.
